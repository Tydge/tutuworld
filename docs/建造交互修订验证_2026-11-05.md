# 建造交互修订验证 · 2026-11-05

本轮修改位于本机源码工作树；未部署、未发布安装包。测试使用 `--test` 隔离会话，未改写真实玩家进度，未重建成品地图。

## 最终行为

- 材质接缝：楼板按材质批量生成，删除相邻单元（含跨渲染块）之间共面的内部侧面；外露边缘、楼梯井侧边和真实碰撞保留。建造园两块路牌的立柱后移，消除柱面与牌面的共面重叠，已生成地图在加载时同样修正。
- 楼层：取消固定1～4楼下拉，用上下按钮或PageUp/PageDown浏览已有楼层。最高层再向上为屋顶，向下回到室内；完整墙壁开关跨层保留，但不会打开屋顶。已有上层地板也可编辑，保证先铺地板、再装楼梯的加建流程；在屋顶选择地板可创建下一层，最多四层。
- 门窗：移动预览只检查支撑墙段、开口间距，复用模型并关闭预览投影；不重新生成墙洞，不全量校验建筑。点击放置才走原有完整校验、真实墙洞更新与原子存档。
- 灯具：16→48盏（含壁炉），保留楼层隔离、距离淡出及阴影距离剔除。原限制用于控制实际光源与阴影渲染成本；提高上限不代表任何摆放密度下都保证60FPS。
- 样板：底部目录里的简化模型小图卡片，仅保留“温馨小屋”和“两层楼阁”。两层楼阁取自本机2026-11-05玩家修改后的83条建筑记录（39件家具，7盏灯），支持件引用完整；温馨小屋28条。模板不含角色、时间、资产或账户数据。林间小屋只移除模板选项，不删除世界里已建房屋。原一次性样板迁移保持不变。

## 整帧性能探针的限制

`multistorey_performance`完成6个视角和3种楼梯预览，但本次每个2秒窗口只收到5～6次 `frame_post_draw` 回调，完整帧中位50.7～515.0ms、P95约970ms，CPU渲染提交中位2.09～4.61ms。记录来自当前Mac桌面图形会话，窗口尺寸还从请求的1920×1080恢复为3024×1890。该探针仅以无脚本错误退出作为PASS，不设置帧率门槛；本次稀疏回调数据不能用于宣称稳定帧率或与之前的性能基线直接比较。未据此声称整体性能验收通过。原始记录见[performance-probe.json](evidence/building-feedback-20261105/performance-probe.json)。窗户局部CPU计时与48灯实际渲染功能检查为独立结果。
