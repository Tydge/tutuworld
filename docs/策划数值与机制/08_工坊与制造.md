# 工坊与制造

已于2026-11-02随0.3.3／build 6发布，客户端和公共服务器同步更新。

## 入口与流程

铜叶工坊位于城镇北侧、海风小厨房的东边。按E推门进入，再靠近室内“制造工作台”按E查看配方。查看菜单不占台，实际制造期间占用该工作台；其他工作台可独立使用。

制造需要对应等级、全部材料、未拥有的产物，以及1点生产耐力。开始时预留耐力，完成时扣材料、发1件产物和技能/总经验；取消、离开工作台或条件变化时不扣材料，并退回预留耐力。任务不能与浇水、烹饪、取水或其他生产同时进行。重启不补发未完成任务奖励，保存失败不产生重复工具或经验。

铜水壶容量和取水规则见[02水井与水壶](02_种植与采集机制.md)。它制成时为空壶，持有后自动优先使用。铜斧仍需满足既有伐木Lv.3才能采集桦木；制造等级不替代工具的使用等级。铜斧原工具店购买途径保留，价格只在[04](04_物品商店与服装.md)维护。

工具唯一持有，已经拥有时不能再次制造；不增加重复工具、出售工具或回收拆解机制。后续配方通过同一数据结构增加材料、制造等级、基础时长和经验。

## 制造技能与速度

技能ID为`manufacturing`，属性ID为`manufacture`，角色面板分别显示“制造技能”和“制造速度”。新旧角色新增技能均从Lv.1／经验0开始；保留原有五项技能进度。曲线与等级上限沿用[01](01_全局规则与角色成长.md)，每一级提供1%制造速度，包括Lv.1。

`实际时长=基础秒÷max(0.2,1+基础属性+装备+食物+制造等级×0.01)`。当前无其他加成时，Lv.1为10÷1.01≈9.90秒；完成以上两件工具累计10经验，升至Lv.2。烹饪与制造分别结算技能经验、等级门槛和速度来源，不互相增加经验。

## 可复用与权威边界

工作台为独立家具模块，保留`module_id`、`module_type`、本地变换、子碰撞和三个挂点：`ActionAnchor`交互、`WorkAnchor`角色操作位、`EffectAnchor`工具命中位置。房屋使用结构化蓝图和独立场景，水井也使用同样的稳定实例ID和挂点登记机制。地图调整或未来移动/旋转实例后，客户端及服务端均从实际挂点刷新位置。

配方`station=workshop`，不能在厨房执行；厨房的7道料理也不会进入工坊菜单。多人操作由服务端核对地图、真实位置、房屋内部、占用和落点，产物、材料、水量与经验均属于操作者。未来建造编辑器的放置校验、导航刷新、布局存档、费用、撤销和共享权限仍需另行实现。
