## 本地新增模块与移动约定

铜叶工坊位于厨房东侧，独立房屋场景`scenes/workshop.scn`，蓝图`data/houses/crafting_workshop.json`。谷仓从(35,0,-17)移至(42,0,21)，北街向东延长；铜矿迁移见02。菜园原48块地和菜地ID不变。

水井由`data/production_objects.json`定义，根节点包含结构、屋顶、吊桶、碰撞和本地挂点；工坊工作台是独立家具模块。生成时只在模块内部合批，禁止并入整张地图的大批次。水井顶棚遮住角色时淡出。

`production_facilities.gd`按稳定实例ID登记实际场景节点；客户端与服务端均用挂点的global transform刷新目标位置和权威距离。移动/旋转水井、家具或整栋工坊时，子碰撞、操作位与特效位置一起移动；房门独立登记。本地建造园已实现结构和目录物件的ID、放置校验、持久化、导航刷新及撤销；水井/制造工作台尚未加入玩家放置目录，生产设施建造事务、费用和多人权限仍待接入。

门口跨阶沿运动方向覆盖脚部宽度采样，避免斜走时身体先撞到18cm门槛而中心探针仍在低处。仍限制小于32cm、斜率可站立且头部上方无阻挡；关闭房门和过高台阶继续阻挡。商人和普通NPC对话需要无实体墙/关门阻隔；商店买卖还需要进入对应店铺，在实际提交时重新检查。

### 菜地实例

48块菜地，6行×8列，使用以下生成规则即可定位全部实例：

| 字段 | 规则 |
| --- | --- |
| 行r、列c | r=0～5，c=0～7 |
| 稳定ID | `plot_`+两位编号，编号=8×r+c，即plot_00～plot_47 |
| 提示坐标XYZ | `(22+2.25×c, 0, -6+2.5×r)` |
| 外观高度 | Y=0.17 |

编号与存档绑定。例如plot_00=(22,0,-6)，plot_47=(37.75,0,6.5)；改布局必须迁移存档及照料记录。
