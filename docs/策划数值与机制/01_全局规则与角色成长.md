## 01 全局规则

| 规则 | 数值 | 单位或说明 |
| --- | --- | --- |
| 世界一天 | 3600 | 现实秒=24游戏小时 |
| 新世界初始时刻 | 单人08:00／多人00:00 | 多人从正式建服1年1月1日开始；发布后一次性对齐现实整点=游戏零点 |
| 离线世界推进上限 | 单人7／多人不限 | 现实天；不会跳过未完成照料 |
| 基础耐力上限 | 100 | 点；容量加成后向下取整 |
| 生产耐力 | 常规1／二级采集2 | 开始预留，取消/失败按实际预留退回 |
| 奔跑耐力周期 | 3 | 累计现实秒/点；余量跨停顿/存档保留 |
| 自然恢复周期 | 30 | 现实秒/点，移动时也恢复 |
| 睡眠恢复倍率 | 2 | 无加成时15现实秒/点 |
| 同时任务数 | 1 | 生产、用餐或零食一次一项 |
| 料理用餐 | 6 | 现实秒；不消耗生产耐力 |
| 橘子食用 | 3秒／恢复3点 | 背包使用；完成扣1颗，取消不扣，满耐力不可吃 |
| 持续料理效果 | 1 | 游戏天；同组新餐替换旧餐 |
| 基础步行速度 | 2.8 | 场景单位/现实秒 |
| 奔跑基础倍率 | 1.7 | 另乘奔跑速度属性 |
| 跳跃初速度 | 7 | 场景单位/现实秒 |
| 重力 | 18 | 场景单位/现实秒² |
| 动作移动取消距离 | 1 | 距动作起点的三维距离 |
| 属性倍率下限 | 0.2 | 最终倍率=max(0.2,1+加成) |
| 交易数量 | 1～99 | 工具/服装单次仅1，且不可重复购买 |
| 自动保存周期 | 15 | 现实秒，另在结算等节点保存 |

耐力恢复使用现实时间并支持离线；测试调整当天时分会平移Buff/资源期限，不能借此恢复耐力。玩家在床上睡眠不跳到次日。金币恢复范围0～99,999,999，普通物品恢复数量上限99,999，基础属性恢复范围-0.8～10；这些是存档清洗边界，不是新增背包玩法。

多人新角色统一500贝壳币、无初始种子、保留一件自选服饰；单人保持下表。公共世界的日历和交互规则统一见[多人公共世界](../多人模式设计草案.md)。

## 04 属性定义

| 属性ID | 显示名称 | 技能来源／主要作用 |
| --- | --- | --- |
| stamina_capacity | 耐力值 | 容量=100×倍率后向下取整 |
| stamina_regen | 耐力回复速度 | 恢复计时速度乘倍率 |
| move | 移动速度 | 步行和奔跑共同基础移动倍率 |
| run_speed | 奔跑速度 | 只在奔跑时额外乘倍率 |
| water | 浇水速度 | 种植每级+1% |
| plant | 播种速度 | 种植每级+1% |
| weed | 除草速度 | 种植每级+1% |
| harvest | 收获速度 | 种植每级+1%；包括橘子采摘 |
| cook | 烹饪速度 | 烹饪每级+1% |
| stone | 采石速度 | 采石每级+1% |
| mining | 采矿速度 | 采矿每级+1% |
| wood | 采木速度 | 伐木每级+1% |

加成相加：角色基础＋装备＋当前食物＋技能。0.15代表15%，Lv.1即1%、Lv.100为100%；工作耗时=基础秒÷倍率。最终奔跑速度=2.8×移动倍率×1.7×奔跑倍率；奔跑属性不影响步行。属性悬停逐行显示真实来源与数值，技能悬停显示简短用途。当前服装均无属性加成。

## 05 技能定义

| 技能ID | 名称 | 加速范围 | 其他本轮效果 |
| --- | --- | --- | --- |
| planting | 种植技能 | 播种、浇水、除草、收获 | 作物等级门槛、照料品质暴击 |
| cooking | 烹饪技能 | 烹饪 | 配方等级门槛 |
| mining | 采矿技能 | 采矿 | 工具/材料门槛、双倍产量 |
| quarrying | 采石技能 | 采石 | 工具/材料门槛、双倍产量 |
| woodcutting | 伐木技能 | 采木 | 工具/材料门槛、双倍产量 |

成功种植动作/一级采集经验1，二级采集2；料理按03配方经验。总经验同步记录同量生产经验；产量翻倍或品质增加不再多加经验。吃饭、零食、交易、换装不给经验，取消/失败也不发。

## 06 等级曲线
