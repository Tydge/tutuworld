# 全局规则与角色成长

当前实现：0.3.3 · 发布日期：2026-11-02；包含水井、有限水量与制造工坊。

维护时间、耐力、角色初始、属性和技能。动作、作物和采集见02，全部买卖价格只在04维护。

编辑约定见[目录](README.md)。

耐力恢复使用现实时间并支持离线；测试调整当天时分会平移Buff/资源期限，不能借此恢复耐力。玩家在床上睡眠不跳到次日。金币恢复范围0～99,999,999，普通物品恢复数量上限99,999，基础属性恢复范围-0.8～10；这些是存档清洗边界，不是新增背包玩法。

公共世界日历和交互占用见[07多人公共世界](07_多人公共世界.md)。

## 角色初始

三种物种ID：`bunny`兔兔、`cat_teacher`猫咪、`panda`熊猫；数值相同。出生在`city (0, 0.1, 9)`，多人由服务器避让占位后选取附近安全位置。

| 项目 | 单人新角色 | 多人新角色 |
| --- | --- | --- |
| 贝壳币 | 650 | 500 |
| 初始种子 | 胡萝卜3、生菜3、番茄2、南瓜2 | 无 |
| 初始服饰 | 九选一，发1件并穿戴 | 同单人 |
| 耐力／总经验 | 100／0 | 同单人 |
| 六项技能 | Lv.1，经验0 | 同单人 |
| 基础属性加成 | 全部0 | 同单人 |

初始服饰仅含`bow_rose/sage/honey`、`scarf_red/blue/green`、`vest_rose/sage/honey`（斜杠表示可选后缀）。格纹蝴蝶结和小麦种子不赠送。名字1～12字符、不含控制字符；单人同档不重名，多人全服不重名，均忽略大小写。

世界时钟、菜地和资源共享；金币、背包、装备、总经验、技能与耐力属于角色。线上角色不导入单人资产，账号规则见07。

## 属性定义

| 属性ID | 显示名称 | 技能来源／主要作用 |
| --- | --- | --- |
| stamina_capacity | 耐力值 | 容量=100×倍率后向下取整 |
| stamina_regen | 耐力回复速度 | 恢复计时速度乘倍率 |
| move | 移动速度 | 步行和奔跑共同基础移动倍率 |
| run_speed | 奔跑速度 | 只在奔跑时额外乘倍率 |
| water | 浇水速度 | 种植每级+1% |
| plant | 播种速度 | 种植每级+1% |
| weed | 除草速度 | 种植每级+1% |
| harvest | 收获速度 | 种植每级+1%；包括橘子采摘 |
| cook | 烹饪速度 | 烹饪每级+1% |
| manufacture | 制造速度 | 制造每级+1% |
| stone | 采石速度 | 采石每级+1% |
| mining | 采矿速度 | 采矿每级+1% |
| wood | 采木速度 | 伐木每级+1% |

加成相加：角色基础＋装备＋当前食物＋技能。0.15代表15%，Lv.1即1%、Lv.100为100%；工作耗时=基础秒÷倍率。最终奔跑速度=2.8×移动倍率×1.7×奔跑倍率；奔跑属性不影响步行。属性悬停逐行显示真实来源与数值，技能悬停显示简短用途。当前服装均无属性加成。

## 技能定义

| 技能ID | 名称 | 加速范围 | 其他效果 |
| --- | --- | --- | --- |
| planting | 种植技能 | 播种、浇水、除草、收获 | 作物等级门槛、照料品质暴击 |
| cooking | 烹饪技能 | 烹饪 | 配方等级门槛 |
| manufacturing | 制造技能 | 工坊制造 | 制造配方等级门槛 |
| mining | 采矿技能 | 采矿 | 工具/材料门槛、双倍产量 |
| quarrying | 采石技能 | 采石 | 工具/材料门槛、双倍产量 |
| woodcutting | 伐木技能 | 采木 | 工具/材料门槛、双倍产量 |

成功种植动作/一级采集经验1，二级采集2；料理按03配方经验。工坊制造经验按[08配方](08_工坊与制造.md)发放。总经验同步记录同量生产经验；产量翻倍或品质增加不再多加经验。吃饭、零食、交易、换装不给经验，取消/失败也不发。

## 等级曲线

升级需求为`(当前等级+1)×(当前等级+4)`，等级上限100，技能经验封顶于满级累计值，不继续积累溢出经验。到达100累计353,496技能经验，满级经验条显示“已满级”。下表仅为公式核对点，修改曲线时以本节公式和明确的例外为准，不再重复手填100份相同推导。

旧角色五项技能通过`skill_rules_version=2`一次性重置为Lv.1/经验0，金币、物品、总经验、地图与世界进度保留；新规则下重新获得的技能经验再次保存/载入不重置。已有作物保留生长，缺少品质字段时按0恢复。

新增制造技能从Lv.1/经验0补齐，不提升`skill_rules_version`，不再次重置已有五项技能。水壶剩余水量按角色、按工具保存，旧存档缺失时为空壶；取水不获得技能或总经验。
