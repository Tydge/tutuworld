### 时间与耐力

| 整理标识 | 规则 | 目标值 | 单位或触发 | 当前机制说明 |

### 恢复与存档中的开发约束

下列是读取旧存档时的清洗边界，不代表在线交易或背包已经实现同名容量玩法。改动时需同时核对保存、恢复和显示。

| 规则 | 当前基线 | 说明 |
| --- | --- | --- |
| 金币恢复范围 | 0～99,999,999 | 当前加减金币不统一按此上限截断 |
| 普通物品恢复数量 | 1～99,999 | 不是已实现的单格堆叠上限；零数量移除 |
| 工具/服装恢复数量 | 1 | 唯一持有 |
| 总经验及技能经验恢复范围 | 0～2,147,483,647 | 技能结算也截断到此上限 |
| 属性存档加成范围 | -0.8～10.0 | 0.15表示+15% |
| 技能设计等级范围 | 1～50 | 当前经验范围造成可达等级冲突，见06 |
| 自动存档间隔 | 15现实秒 | 另在完成动作、换装、交易等节点保存 |

自然/睡眠恢复支持离线，使用现实时间；单人调整当天时分会平移Buff和资源刷新期限，不借此恢复耐力。新建角色共用菜地、节点和世界时钟；钱、背包、经验、技能、耐力与穿搭独立。

## 04 属性定义

加成存储口径：0.15=+15%，0=无额外加成。总加成=角色基础加成+已穿装备加成+当前食物加成；最终倍率=max(0.2,1+总加成)。当前所有服装均未配置属性加成。

| 属性ID | 名称 | 初始加成 | 作用 |
| --- | --- | --- | --- |
| stamina_capacity | 耐力值 | 0 | 基础耐力100×倍率后向下取整，至少1 |
| stamina_regen | 耐力回复速度 | 0 | 恢复计时速度乘倍率 |
| move | 移动速度 | 0 | 基础移动速度×倍率 |
| water | 浇水速度 | 0 | 浇水基础秒/倍率 |
| plant | 播种速度 | 0 | 播种基础秒/倍率 |
| weed | 除草速度 | 0 | 除草基础秒/倍率 |
| harvest | 收获速度 | 0 | 作物收获与橘子采摘基础秒/倍率 |
| cook | 烹饪速度 | 0 | 配方基础秒/倍率 |
| stone | 采石速度 | 0 | 石灰石/砂石采集基础秒/倍率 |
| mining | 采矿速度 | 0 | 铜矿/铁矿采集基础秒/倍率 |
| wood | 采木速度 | 0 | 树枝/桦木采集基础秒/倍率 |

示例：浇水速度+30%时，2现实秒变为2÷1.3≈1.538现实秒。烹饪不属于食物`farm`加成；浇水单独对应`water`。

来源：[character_stats.gd](/Users/wangtaizhi/兔兔的世界/scripts/services/character_stats.gd)、[local_authority.gd](/Users/wangtaizhi/兔兔的世界/scripts/services/local_authority.gd)。
