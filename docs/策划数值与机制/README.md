## 单位和基线

现实秒用于操作、移动、耐力与淡入淡出；游戏天/世界时分用于成长、刷新、作息、持续增益。0.15表示15%，基础耗时除以总速度倍率。ID优先保留，空值和0分开。

`.核对基线/当前已实现/`保存本轮同步后的文档和数据，供下次修改比较；原始初稿及本轮开发前资料仍保留，不覆盖历史。正常只修改本目录顶层8份MD，不重跑旧制作脚本覆盖手工设计。实现事实入口另见项目开发接手指南，验证证据在项目`.qa-artifacts`。
