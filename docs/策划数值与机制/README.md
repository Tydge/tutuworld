## 交给开发时

1. 修改对应正文；新增机制写清触发、条件、结果和取消/失败处理。保留稳定ID，新增或删除ID说明旧存档如何处理。
2. 在下面简记待实现条目；开发对比Git中的最近发布标签和当前代码，核对所有正文差异，包括未登记的手工修改。
3. 实现后更新受影响文档、物品说明与[验证基线](../验证基线.md)，填写实现版本；当前值和未来目标有差异时明确标注。

| 条目／ID | 目标变化与预期 | 状态／实现版本 |
| --- | --- | --- |
| 冰原岛与移动 | 第三张地图、32 处采集点、码头选目的地、玩家提速与跑步免耗耐力 | 已随 0.5.0 上线 |
| 耳根立体蝴蝶结 | 完整造型和三物种定位 | 0.3.3已发布 |

| 环境美化／单人建造园 | 见05及[建造说明](../建造模式.md) | 0.4已发布；操作见建造说明 |

玩家可在海岛城四块、冰原岛八块和玉京城六块地皮上建造。单人和多人都支持 1～4 楼、楼梯、拖墙扩建、内外墙独立装修及室内布置。玉京的辘轳井可补水，百工案可生产。玩法和施工同步分别见[建造说明](../建造模式.md)与[多人公共世界](07_多人公共世界.md)。

后续策划条目仍包括建材经济、料理品质、更多技能效果和跨服或选服。

## 单位与历史

现实秒用于动作、移动、耐力和淡入淡出；游戏天/时分用于成长、刷新、作息和持续增益。属性小数0.15表示+15%；动作时间=基础耗时÷最终速度倍率。空值与0含义不同。

当前运行版本来自[scripts/services/release.gd](../../scripts/services/release.gd)。规则、数据及文档随源码一同提交，本版对应[发布记录](../0.6.3_多人建造与玉京样板.md)和 `v0.6.3` 标签。开发入口见[接手指南](../开发接手指南.md)。
