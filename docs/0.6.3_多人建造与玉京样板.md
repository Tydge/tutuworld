# 0.6.3 多人建造与玉京样板

0.6.3 / build 15，网络协议 5，启动器 2。到自己的地牌旁按 Shift+F6 进入建造。「创建样板房」收录玉京的 12 款房型和 3 款楼廊。放下后可拖墙扩建、移动门窗、改内外墙颜色。手建可逐格铺青砖、画墙、装门窗再盖重檐。编辑当前楼层时屋顶自动让开。为放进玩家地皮，含章殿样板的平面尺寸按地图原殿的约 77% 取整到半米网格，保留朱墙、格窗和琉璃重檐，放下后仍可向外扩建。[建造操作与旧房转换](建造模式.md#玉京房屋的手建和扩建) · [含章殿外观](evidence/production-0.6.3/palace-exterior.jpg) · [扩建后的室内](evidence/production-0.6.3/palace-interior.jpg)

## 同图施工为何会卡

施工时街上的居民模型已暂停，旧客户端仍在接收、插值并遍历同图所有居民，还会因周期性世界快照刷新地皮和农田。六名角色在玉京城测了三组，每组约 3.1 秒。旧版每个施工客户端收到 1,104 至 1,242 条居民动作和 4 个完整快照。新版三组均为零，施工边界、在线玩家的位置、制作结算和完工结果继续同步。步行玩家照常收到居民与世界更新。

在放有六座含章殿的地图，拖墙原先要查找整张地图的 5,472 格地板，现在只检查该地皮的 912 格。选取墙地时复用当前楼层及剖面的碰撞列表。服务器发来的楼层字段在接收时转回整数，邻居交房后，原房屋二楼的墙、栏杆和屋顶继续使用原模型。

本机对同一组地板分别测量了一次冷缓存拖墙准备，整图耗时 46.22 毫秒，只算自家地块耗时 4.35 毫秒。

同图短时间收到多份完工请求时，服务器逐块核对所有权、修订号、仓库余额及角色安全，分别持久化。随后按地图合并模型、碰撞和寻路更新。施工围栏在碰撞就绪后开放。玉京屋顶的权威模型保留与客户端一致的天花板碰撞。

## 复验

- `python3 tools/dev.py test concurrent_building --timeout 240` 在同一张玉京地图运行六个独立 WebSocket 客户端，覆盖 1 人、2 人和 6 人施工、同图旁观者持续收到居民动作、续约及六人同时完工。校验每块地的构件、所有客户端和磁盘存档。
- `python3 tools/dev.py test building_multiplayer_flow --timeout 240` 使用独立的 18919 端口账号服务。实际操作同图两栋房，检查邻居完工期间的草稿、撤销、放弃、增量替换和地皮边界。
- `python3 tools/dev.py test jade_building_rules jade_workshop_flow drafting_flow --timeout 200` 覆盖样板四向落地、拖墙、逐格手建、屋内摆家具及旧房转换。六客户端压力用例测网络与权威模拟，带画面的编辑器另行测试。

## Linux 同图实测

正式机上的独立 Linux 试服使用单独的账号库和世界。六个客户端从玉京六块地牌旁登录，逐个进入建造。每档稳定后采样 4.5 秒，表中频率由客户端收到的服务器 tick 计算。

| 同图施工人数 | 服务器模拟频率 | 每名受测施工者收到的居民动作 / 周期世界快照 |
| ---: | ---: | ---: |
| 1 | 61.1 Hz | 0 / 0 |
| 2 | 60.2 Hz | 0 / 0 |
| 6 | 60.7 Hz | 0 / 0 |

六人同时确认六座含章殿时，从发起请求至收齐确认，逐笔重建用时 30.426 秒，合并后为 8.065 秒。最终服务端日志记录了一次几何更新，共生成 203 个模块。完成后六个客户端都看到了全部 90 条构件，施工围栏已撤，居民动作恢复。此项测量覆盖网络和服务器模拟；图形交互使用 Mac 单机、双客户端另验。

## 正式发布与存档

2026 年 11 月 28 日发布 0.6.3 / build 15。切换前备份和切换后核对覆盖全部 3 个账号、4 个角色、地皮归属与版本、照料历史，以及海岛城 154 条、冰原岛 102 条、玉京城 12 条已建记录。测试用的六座殿堂只存在于隔离试服。首次切换因两名离线角色缺省的临时姿态在启动时写成空字典而回退。核实 0.6.2 和 0.6.3 都执行相同的初始化后，复核确认所有持久字段一致，随后切换并停止试服。[备份位置和恢复说明](服务器运维.md)

公网健康检查返回 build 15。正式 WSS 接受本版并提示旧版更新，客户端从正式地址下载完整的 251,568,560 字节资源包，通过签名和 SHA-256 校验。Mac 通用安装包已验签，在 Apple Silicon 上分别启动新版原生程序、用旧版启动器挂载新版资源包。Windows x64 安装包已解压校验可执行文件、游戏资源与 D3D12 运行库，实体 Windows 机器尚未实测。部分 Godot 测试进程在退出时报资源仍被引用，游戏启动和上述用例断言均已通过。[构建摘要](evidence/production-0.6.3/artifacts.json) · [实测摘录](evidence/production-0.6.3/verification.txt)
