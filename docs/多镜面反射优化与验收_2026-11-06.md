# 多镜面反射优化与验收 · 2026-11-06

本轮已实现多镜面共面共享、逐帧同步与纹理绑定复用，但**尚未完全达到“20面任意布局、画面无损、始终不掉帧”**。同墙20面与四周墙面安装20面的场景通过P99小于16.7ms的性能检查；20个不同平面同时可见仍未通过。共享后采样细节保持，但Godot方向光阴影随捕获视锥改变，画面并非逐像素一致。不能将本轮写成完整目标已完成。

验收时的源码与证据已纳入功能提交`ce15a7b`；随后清理无调用代码并更新交接，未部署发布、修改真实存档或重建地图。前序屋顶选取与唯一墙体开关修复仍保留，见[前序记录](墙壁选取与镜面同步验证_2026-11-06.md)。

## 实现与取舍

- 删除两面镜子/总反射像素的硬上限。每面可见镜都更新当前帧；没有交替刷新、冻结人物、增加距离开关或降低原有64～640像素的单面需求。
- 同平面、同法线的镜子具有同一个反射眼点。用平面坐标合并捕获区域，每面镜子通过自己的UV仿射映射截取正确视角。空隙过大、投影密度相差超过2倍或目标边超过4096像素时拆组，避免为大片空白渲染。
- 用主相机视锥裁剪部分屏外的镜面。为紧凑共面组预留同平面镜面区域，按2的幂分配/复用纹理，保留足够的双线性采样边界；明显缩小时稳定1秒后才缩容。
- 屏外停止渲染，保留纹理绑定30秒。原先反复把ViewportTexture置空再绑定会在Metal上产生明显长帧；保留绑定消除了反复进出屏幕边缘的这类等待。首次分配/首次使用仍可能出现长帧。
- 实墙/楼板的真实BoxShape实体内缩2厘米后建立原生遮挡体，主视图与反射视图共用。门窗、楼梯开洞沿原有实体分块保留；剖切、淡出、隐藏和仅投影结构不参与错误遮挡。固定场景开关遮挡的镜内像素P99差为0。

镜内仍不递归绘制其他镜面，沿用前序实现。主画面均衡档约200万3D像素、4×MSAA；反射2×MSAA、原方向光阴影与原渲染距离保留。尚未加入SSR、探针或光追替代。

试验过减少阴影级联、无接收体时省阴影、封闭房间缩短远裁面、原生BVH合并查询等办法。它们有的改变阴影结果，有的脚本/同步成本抵消收益；这些试验没有进入最终源码。诊断原型已清理，否决试验保留[原始日志](evidence/mirror-many-20261106/rejected-single-cascade.log)；不能当正式功能。

## 研究依据

| 路线 | 结论与来源 |
| --- | --- |
| 平面反射 | 可见主镜头背后的角色/物件，但需要额外渲染场景；成本包含几何、draw call和阴影，单纯降低纹理尺寸无法消除这些成本。[Epic官方说明](https://dev.epicgames.com/documentation/en-us/unreal-engine/planar-reflections-in-unreal-engine) |
| 共面共享 | 同一个反射眼点可以供多个镜面窗口取样，这是本轮采用的几何性质；不同高度、同墙的镜子仍共面。不同墙面/平行但错开的平面不能直接共用同一视角。[平面反射插件作者关于共面共享的原始说明](https://discussions.unity.com/t/legacy-pidi-planar-reflections-2-real-time-reflections-with-lightweight-srp-mobile-support/669312?page=7) |
| 场景遮挡 | 只做视锥裁剪仍会提交墙后场景，原生遮挡体能避免绘制看不见的部分。[Godot性能文档](https://docs.godotengine.org/en/4.6/tutorials/performance/optimizing_3d_performance.html)、[Viewport开关](https://docs.godotengine.org/en/4.6/classes/class_viewport.html) |
| SSR/探针 | SSR缺失屏外物件；探针是从探针位置捕获的环境，不能自动得到精确的镜面视差，不能直接满足本任务的真实人物镜像要求。[Epic的SSR对照](https://dev.epicgames.com/documentation/en-us/unreal-engine/planar-reflections-in-unreal-engine)、[Godot ReflectionProbe](https://docs.godotengine.org/en/4.6/classes/class_reflectionprobe.html) |
| 深度重投影/隔帧/动态降分辨率 | 可以省成本，但新显露区域、人物动作或细节可能出错；本轮没有用来通过验收。多独立平面进一步优化可能需要渲染器层面的多视图、共享阴影或专用反射通道，不能只改刷新频率。 |

还核对了Godot 4.6.3的[方向光阴影构建源码](https://github.com/godotengine/godot/blob/4.6.3-stable/servers/rendering/renderer_scene_cull.cpp)：其级联按相机投影与范围重建。合并捕获视锥会改变阴影分配，因此“共享纹理”本身不等于整幅渲染数值无损。未找到EA公开的《模拟人生3》镜面渲染源码或20面同时可见的同条件测量，不能据此承诺本项目零成本的真实镜像。

## 验证方法与边界

MacBook Pro / Apple M1 Pro / macOS 15.6.1 / Godot 4.6.3 / Metal Forward+。原生窗口3024×1890，3D比例约0.592。全城镇、真实目录镜子/家具/灯具、运动镜头、移动并播放动作的角色；NPC在建造模式按原规则暂停。使用隔离测试进度。

关闭VSync/FPS上限与自动绘制循环，每个process_frame执行一次force_draw，计整帧墙钟时间，包含主视图、脚本及反射，避免把GPU计时或CPU提交时间充当FPS。每个条件4秒；关闭反射的基线使用相同镜头路径。先记录30帧冷启动，再预热60帧；首次转到新平面的分配长帧仍计入日间路径，未从统计剔除。P99达标不等于每一帧都达标。

三种布局：同墙两排共20面、20个独立平面同时可见、18×18米房间四周每墙5面。四周墙面场景一次可见约3～7面，不能将其当20面同时可见；同墙与独立平面场景同时可见20面。

同墙20面从逐面捕获20次变为1次；放开旧算法两面上限后的有效同墙压力基线中位21.515ms，本轮10.216ms。该基线是旧逐面算法的20面反事实压力测试，不是原两面上限行为，也不是所有布局可推广的节电测量。冷启动前30帧最长分别为：同墙18.730ms、独立平面58.873ms、房间37.183ms；房间首次转动路径仍有3帧超过预算。

## 画面对照

20面共面镜的80个角点与实际反射相机投影最大误差约0.00067纹理像素，阈值0.01。匹配世界采样密度后，2327个彩条样本平均通道误差约0.00056，P99约0.000073；镜中各自视角、颜色与细节通过对照。原生实墙遮挡开关对4500个镜内样本的P99误差为0。

**整幅画面仍不等价**：包含地面/阴影的4500个样本平均最大通道差约0.0267、P99约0.326。差异集中于方向光阴影，不能用彩条测试通过来掩盖它。保留了[共享截图](evidence/mirror-many-20261106/quality-shared.jpg)和[独立捕获截图](evidence/mirror-many-20261106/quality-reference.jpg)。后续需要消除或证明这些阴影变化不构成画质回退，才可宣称无损目标完成。

清理前的源码哈希对应`ce15a7b`中的文件，不应拿来校验清理后的代码；最新快照和检查见[交接证据](evidence/handoff-final-20261106/summary.json)。

## 回归与复现

功能回归7组668项通过：project_integrity、wall_furniture_rules、wall_furniture_flow、building_selection_flow、fixture_lighting_flow、multistorey_editor_flow、mirror_many_flow。功能用例另用6帧交替颜色的真实物体逐镜读回，确认120次镜面画面显示当前帧；检查20面实际安装、逐帧更新计数、颜色/投影、遮挡、35米距离、屏外停绘与原墙壁选择修复；功能通过不代表全部性能条件通过。

```sh
python3 tools/dev.py test --suite mirrors --windowed --timeout 240
python3 tools/dev.py test mirror_many_performance --windowed --timeout 240
# 单独复现某布局：coplanar / room / independent
python3 tools/dev.py test mirror_many_performance --windowed --game-arg=--layout=independent
```

性能用例保留严格P99<16.7ms断言；独立平面条件失败会返回非零，没有降低验收线。可加`--game-arg=--trace`保存逐帧目标尺寸/耗时诊断。

代码入口：`scripts/city/mirror_reflections.gd`（调度、分组、纹理生命周期）、`mirror_plane.gd`（几何、视锥、UV）、`mirror_occluders.gd`（实墙/楼板遮挡体）、`assets/shaders/planar_mirror.gdshader`（每镜UV）、`tests/mirror_many_flow.gd`（真实20镜、图像和性能对照）。
