# 多人公共世界 · 0.3.1

更新：2026-11-02。本文记录已实现规则，未来新增设计直接修改相应条目；部署与维护见[服务器运维](服务器运维.md)。

## 账号、进度和公共世界

- 标题选择多人游戏，直接注册或登录账号，再创建兔兔、猫咪或熊猫。一个账号同时只能有一个角色入场。
- 多人角色从500贝壳币、零种子和一件自选初始服饰开始；不导入单人资产。原单人存档与650币及初始种子规则保留。
- 金币、背包、技能、耐力、食物效果、穿搭和位置属于角色。城镇、山谷、菜地、资源、门和NPC属于服务器公共世界。
- 删除进入地图后的欢迎/探索提示整行；必要的交互与失败提示保留。
- 当前运行一个长期公共世界，首期约5人；以后房间按独立服务器/数据目录隔离。尚无选服和跨服转移界面。
- 本轮不提供共享仓库、木箱或存取流水。

## 菜地、资源和照料记录

城镇菜地公用，每个人都可播种、浇水、除草和收获，但必须达到当前作物的技能门槛。材料与耐力由操作者承担，经验给操作者，作物给收获者。品质留在本茬作物上，由每次操作的实际操作者判定暴击。二级采集消耗2耐力，其余既有生产规则不变。

按E打开照料面板，可查看本茬/上一茬记录：操作者、海岛日期时间、动作、品质提升和实际产量。仅成功结算记入记录；其他人照料后界面随服务器快照刷新。记录查看不锁住菜地。资源节点全服共享，成功采集后统一进入刷新倒计时。

## 交互占用与落点

| 对象 | 规则 |
| --- | --- |
| 床、单个座位 | 一人使用，包含NPC正在使用的位置 |
| 料理台 | 实际烹饪期间独占；看菜单不占用 |
| 餐桌 | 实际用餐期间独占；看食物列表不占用 |
| 菜地、资源 | 实际动作期间独占；查看记录不占用 |
| NPC交谈 | 每个NPC同时与一人交谈；不同NPC可分别交谈 |
| 商店 | 先气泡招呼，再按E开店；多人可独立购买 |
| 乘船 | 多人独立结算，落点分别预留 |

玩家间保留实体碰撞。服务端在上线、下船、起床、离座和脱困时检查有效地面、净空、可达区域及其他角色占位，选择附近可用位置，防止同点重叠。没有安全落点时给出简短失败提示：不收取失败旅程的船费，不把起床者强行塞到其他人身上。

设置中的“脱离卡住”由服务端执行，取消当前动作并按实际预留退回耐力，释放占用后移到当前地图附近安全地点；不收费、不额外扣耐力、不跨地图。断线、退出、取消及动作完成会释放对应占用。服务重启不恢复未完成工作或补发奖励，保存时退回未完成工作的预留耐力。

## 同步、聊天和更新

服务器运行真实地图碰撞和NPC作息，裁定移动、交互距离、交易、产量和经验。客户端60 Hz即时预测移动与跳跃，每秒约20批输入，服务端以60 Hz执行受限输入并返回确认序号、每秒约10次广播。客户端对新确认状态重放尚未确认的输入，不逐帧追赶旧位置；远端采用150 ms时间缓冲、最多120 ms外推。短时断流可补算，超过两秒积压重新同步；服务端限制每真实秒可消耗的模拟步数，不接受客户端提交的坐标、任意时间步长或奖励。动作重复请求不会重复扣款、发奖；保存失败会回滚并提示重试。

回车打开聊天输入框，再回车发送，Esc取消；支持中文输入法及emoji。消息仅在同地图角色头顶短暂显示，不提供历史面板，也不落盘保存聊天正文。其他玩家的物种、名字、穿搭、移动、工作、坐卧和持物同步显示。
