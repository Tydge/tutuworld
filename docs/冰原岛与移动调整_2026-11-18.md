# 冰原岛与玩家移动调整

2026-11-18。本轮仅本地源码提交，**没有部署服务器、发布安装包或修改版本号**；正式服务仍为0.4.2/build9。开发分支为 `codex/icefield-island`。

## 本机试玩

用 Godot 4.6.3 打开本工程 `project.godot`，F5进入**单人模式**，到海岛城南码头互动，菜单可选择眠风山谷或冰原岛。出发10贝壳币，返城免费。冰原岛可保存位置并继续游戏；旧存档补入新资源，不重置角色、资产和建筑。

需要隔离试玩时，双击 `tools/本地冰原预览.command`：使用独立测试角色和数据，不读写正式存档。快捷入口只用于主动打开，不会在检查后留下游戏窗口。在线正式服务器尚未部署第三张地图，请勿用正式多人世界验收这轮新增内容。

## 地图与交互

- 西部是轻缓起伏的霜光雪镇、雪松林、三间可进入并交易的商店、木屋、旅舍和极光钟楼；东部是连续蓝冰原。
- 地面范围约356×316米，按2米采样剔除不可行走坡面后约75,084平方米，为当前山谷约25,924平方米的 **2.90倍**。区域内房屋、树干和陈设仍有各自碰撞。
- 三名商人之外新增雪芽、霜铃、松露、小絮四只兔子、米霜猫咪、团雪熊猫，沿真实导航路线行走、可聊天。
- 32处稳定编号的树枝、桦木、铜矿、铁矿、石灰石、砂岩；没有橘子树。木/矿/石沿用采集、耗时、技能、背包、再生和权威校验。
- 北、东、西侧以真实陡雪坡/冰脊阻止继续前进；南侧地面下降到可见海水。逻辑范围保留作兜底，玩家先遇到明确的地貌或水岸。远山三维山麓与远方图带衔接，向开放海域渐入雾色。

## 手感和耐力

所有玩家基础步行由2.8提高至 **3.5**，跑步由4.76提高至 **5.95**，均提高25%；装备、食物和属性倍率继续叠加。NPC巡游速度保持原值。

冰面水平加速度2.3、松键减速度0.72：按移动键时手臂和腿按正常步频动作，实际位移逐渐加速；松键后动作收住，身体继续滑行。跳跃保留冰面水平惯性，空中松键不额外刹车；着陆到雪地恢复正常抓地。预测和远端动作包同时携带冰面惯性与动作速度。

跑步不扣耐力，零耐力也可跑；读取旧存档时清除过去累积的跑步扣点余量。生产消耗、自然恢复、睡眠恢复及食物数值保持原有规则。

## 画面与组件

- 冷杉使用真实枝叶图集、空间实例和独立简化树影，避免整片透明树冠反复投影。
- 粉雪材质、深蓝裂隙冰、随昼夜变化的天空云层、夕照、星空和极光；海面改为小幅且有距离过滤的波纹。
- 全湖共用960像素宽的逐帧反射，静态几何按材质/空间合批；反射不重复运行物理、天气和一套阴影。镜头和投影矩阵每帧同步，不再隔帧捕获。
- 日月位置采用周期方向，跨午夜连续；夜间主光来自上方月光，压低夜间镜面强度，移除午夜海平面的强太阳反光。
- 飘雪是64个稀疏、约1.6像素的小点，近镜头淡出。烟雾与火星保留粒子自身缩放，避免巨大光球。
- 脚印为小圆形、仅轻微压暗雪面的压痕；固定192个实例，22秒内渐隐，不生成持续增长的节点，不在冰面或室内地板留下脚印。
- 营火使用炭木、余烬、石圈和4×4连续火焰图集，按色度与透明度滤除浅底；树冠周围保留8.5米净空。修正相邻雪栅栏端部重叠。

木屋和钟楼的前后山墙已经做成带厚度的封闭三角墙，屋顶按同一坡度延伸出檐。修正合批时混合有/无索引网格导致山墙顶点未被绘制的问题；对保存后的实际网格逐面检查正反朝向及屋顶接缝，避免仅看包围盒误判完整。

商店积雪现在使用**原屋顶材质**，跟随屋顶和雨篷一起避挡，不再另加游离于建筑系统之外的雪屋顶。建造模式选中或放置屋顶时可开关“屋顶积雪”，双坡、四坡、单坡均支持，保存、撤销、重做和权威校验保留该设置。玩家在建筑内部时，自由避挡同时隐藏主屋顶和雨篷；阴影和反射仍保留完整外形。

冬季摆件以地面中心为原点，保留碰撞与互动/效果挂点。14个独立场景与尺寸记录见 `data/winter_objects.json`、`scenes/winter/`：雪人、营火、木材堆、雪栅栏、雪橇、长椅、冰钓点、灯笼、路牌、冰晶、野餐桌、木屋、钟楼、雪松。它们已整理成可供后续建造目录接入的模块；**本轮未把这些摆件的购买入口和价格加入玩家建造目录**。屋顶积雪开关则已接入现有建造界面。

素材、原始图像校验、生成说明及地形来源见 [冬季素材记录](../assets/terrain/winter/ASSET_NOTES.md)。用户参考图未作为贴图使用。

## 验证与限制

统一检查：

```sh
python3 tools/dev.py build icefield --timeout 240
python3 tools/dev.py test --suite icefield --windowed --timeout 240
python3 tools/dev.py test icefield_preview --windowed
```

生成场景必须使用有窗口GL生成器，不能以headless重新保存MultiMesh实例。运行不联网加载地形，生成器和预览入口不进入正式导出。

本轮最终日志、截图和性能数据见 [验收记录](evidence/icefield-20261118/README.md)。性能数据只代表本机Apple M1 Pro和记录中的均衡画质/分辨率，不代表其他硬件保证。美术是否达到参考图的观感仍需实际游玩评价，未把自动测试通过当作主观画面达标。
