# 建造体验对照与后续优先级

初次评估：2026-11-05；实施状态更新：2026-11-06。基于当前未发布源码、实际建造流程和《模拟人生3》资料。已完成房间拖建、正俯视与尺寸、吸管、墙体扩缩、直接拖物和自建用餐；又加入完整下层墙、首座楼梯补整栋上层板、挂墙陈设、真实镜面与UI滚动隔离。本文只维护仍有价值的后续建议，操作以[建造模式](建造模式.md)为准，覆盖见[验证基线](验证基线.md)。

| P1 | 楼梯固定3米宽，落脚区也是3×3米；直梯连两端落脚区占42㎡，U梯占60㎡，相对120㎡温馨小屋很大 | 先提供较窄规格和宽度选择，再优化直/L/U路径与净空；必须核验三物种通行、平台、洞口和护栏 | 小房子能合理容纳楼梯；自动补楼板仍不能消除楼梯本身体积大的问题 |
| P1 | 非法放置主要给通用文本，玩家仍要猜是哪面墙、哪件家具阻挡 | 在模型上突出具体冲突物、门口/楼梯入口及家具互动所需空位，保留取消与撤销 | “放不下”有明确位置和原因，摆放时就能调整 |
| P2 | 单件移动已经可用，已建房屋缺少房间范围选取、批量复制和个人模板保存 | 先支持框选家具、复制房间布置和保存自己的房间蓝图，再考虑既有整栋房屋的组选取 | 能复用自己的卧室/厨房；不再只能使用目录内两套固定整屋样板 |
| P2 | 目录有分类和实际缩略图，但没有搜索、最近使用或收藏，也不能按房间用途浏览 | 增加搜索与最近使用；后续补客厅/卧室等用途筛选 | 减少往返分类查找；当前44种物件，优先级低于建房基本操作 |
| P2 | 屋顶有三造型，但依旧要手画矩形，缺少自动覆盖房屋轮廓、坡度和檐口调整 | 先做屋顶覆盖轮廓预览，再增加坡度、方向与檐口参数 | 凹形房、加层与露台更容易收顶，减少手工拼屋顶 |
| P3 | 落地家具仅90度旋转、半米网格；细部摆设虽有更细吸附，整屋装饰仍受限制 | 提供精细移动/旋转修饰键及角度输入；墙、门窗保持明确结构约束 | 装饰能更自然；需要同步改碰撞/占地校验，不能只转视觉模型 |

11-06已按这三项完成基础操作：拖建房间、正俯视/尺寸标注和吸管复制。更完整的上下层轮廓投影、独立对齐线及个人外观预设仍可继续完善。楼梯瘦身也很重要，但会同时涉及角色通行、网格、实体碰撞与井沿，应作为独立完整改动。

地形编辑、泳池、地下室、建材经济等在《模拟人生3》中有价值，对当前兔兔世界可以后置；此次用户最明显的困难集中在布局和操作。

## 与《模拟人生3》的对应依据

- EA官方手册列出了画房间、整房铺墙地材料、自由放置/旋转、楼层和墙显示快捷操作。值得借鉴的是减少基础操作次数和提供明确空间参照。[EA原版手册，第2页快捷操作及建造章节](https://eaassets-a.akamaihd.net/eahelp/manuals/the-sims-3-manual_PC.pdf)
- Prima的基础建造指南介绍吸管、夜景、网格、撤销及按房间/用途浏览物品。兔兔世界已有夜景、撤销、分类缩略图和部位装修；目前已用E吸管复用现有外观，个人外观预设和用途浏览仍可完善。[Building Basics](https://primagames.com/eguides/the-sims-3-eguide/essentials/creating-a-house/building-basics)
- 《春夏秋冬》时期的Blueprint系统允许选取带家具的预设房间、移动旋转、预览，再确认落地，也可用于高层。可以借鉴“房间级复用”，当前整屋样板旋转只是其中一部分。[Prima：Build/Buy Mode—Blueprints](https://primagames.com/eguides/the-sims-3-seasons-eguide/essentials/buildbuy-mode-blueprints/buildbuy-mode-blueprints)
- 《模拟人生3》的楼梯可选择宽度，也能在上层尚未铺板时从已有下层楼面向上放置；已借鉴后者，加入自动补板与上层楼板生成入口。[楼梯教程](https://www.carls-sims-3-guide.com/buildedit/houses/multilevel/stairs.php)

不把《模拟人生4》的整间拖拽移动、拉伸墙面手柄等行为归到《模拟人生3》名下。上面的框选、整栋选取和操作细节是结合本项目提出的后续设计。

## 当前已有能力与本轮落地

本项目已有真实门窗开洞、半米结构网格、房间识别、墙面内外独立装修、同房间同款批量装修、家具分部位外观、连续放置、真实灯光、逐层建造、三种楼梯、撤销重做和原子建造检查点。这些无需作为“缺失功能”重做。

当前首座楼梯在本栋上层完全无地板时按下层轮廓补齐上层楼板，已有上层楼板时只补缺少的平台；另有“生成上层楼板”的范围预览/确认。加层时保留已有材质、凹角和楼梯洞，可整体撤销。设置增加默认开启的跨层家具显示，关闭时只裁剪当前房屋，屋外仍能看见其他房屋室内家具。实施范围与最新验证见[验证基线](验证基线.md)。

涉及后续工作的代码入口：`scripts/building/editor.gd`、`editor_ui.gd`、`grid_layout.gd`、`room_plan.gd`、`stairs.gd`、`storey_extension.gd`、`structure_shapes.gd`及`appearance_panel.gd`。
