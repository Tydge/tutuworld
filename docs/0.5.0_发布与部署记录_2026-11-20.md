# 0.5.0 发布与部署

2026-11-20 发布。**0.5.0 / build 10 / 启动器 2 / 网络协议 5**包含海岛城、眠风山谷与冰原岛。运行源码提交为 `87e2de3`，含最新的猫咪受光与海岛城阴影修复 `a4a8950`。发布标签为 `v0.5.0`。

[Mac 通用版](https://47.119.37.251/tutuworld/releases/0.5.0/TutuWorld-macOS.zip) · [Windows x64](https://47.119.37.251/tutuworld/releases/0.5.0/TutuWorld-Windows.zip) · [签名更新清单](https://47.119.37.251/tutuworld/manifest.json)

## 本版内容

- 冰原岛新增霜光雪镇、蓝冰原、16 栋可进入的建筑、10 位 NPC 和 32 处采集点。雪镇有三家商店，绒雪裁缝店可试穿并保存居民服装。多人换装同步给同图玩家，跨重启保留。
- 海岛城南码头往冰原和山谷均收 10 贝壳币，两地免费回城。玩家走跑提速 25%，跑步免耗耐力，冰面保留惯性。
- 海岛城重做广场、海豚涌泉、商街、远景和橘树，山谷橘树同步更新。新增紫藤壁挂花箱和四件冬季建造物件。猫咪头部、耳根和脸颊使用连续曲面，脸部随场景受光。海岛城太阳阴影偏移修正角色身上的波纹。
- 多人协议升到 5，覆盖第三张地图和冰面移动字段。启动器仍为 2，老客户端通过签名更新进入新版。旧世界加载时补齐冰原资源，并使用已保存的原资源状态。[接口文档](接口文档.md)

- 本机发布、冰原和海岛城验证见[逐组记录](evidence/production-0.5.0/local-validation.json)。海岛城首次性能测试在码头和施工机位出现长帧，单独重跑后五个机位均通过原阈值。Windows 实体机和 Mac 公证未覆盖。原生更新测试有 Godot 退出时的资源清理提示。
