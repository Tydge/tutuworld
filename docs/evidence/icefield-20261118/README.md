## 已通过的检查

[checks.json](checks.json) 记录每个用例的实际来源批次和结果。包含：三图资源/路线、原有城镇和山谷、角色及存档事务、耐力规则、6名新居民真实移动、26项船程/冰面操作、三物种权威步行3.5/跑步5.95/零耐力跑步、资源物理接近和存档失败回滚、真实屋顶开关/撤销/重做、前后山墙32项实际网格检查、避挡和原有墙面装修。

反射用14次连续镜头轨道变化校验实际图像中标记的位置：每帧均捕获，标记无缺失；最大中心偏差5.47个输出像素，低于6像素条件。边界用实际角色分别向五个方向接近，先遇到陡坡或可见海岸。没有将这些短时检查写成长时或所有设备保证。

## 性能

Apple M1 Pro，Godot 4.6.3，Metal Forward+，均衡画质，实际输出3024×1890，3D缩放约0.592（约200万3D像素），60帧上限。每个机位预热1.8秒，旋转视角采样3秒。

性能脚本关闭自动绘制后每次只主动绘制一帧，避免自动绘制与强制绘制混用造成两次垂直同步等待；这是测试进程的绘制方式，普通Godot Run继续使用正常绘制。原始数据见 [performance.json](performance.json)。
