# 海岛城画面与建造验收

2026-11-20，本地开发分支 `codex/icefield-island`。第一张地图海岛城沿用原有的蓝天、随机云形、昼夜颜色和石路底色。开场视线从广场穿过商街，市民中心铜顶钟楼和远处的风车同时进入画面，南码头能看见海湾灯塔和帆船。

## 海豚涌泉与橘树

两只铜雕海豚立在雕花石座与铜浪上，分块池沿镶有釉面马赛克和贝壳装饰。八个喷头向池内抛水，水束、飞溅的小水滴和落点涟漪同时运动。水滴用一份共享模型按弹道绘制，水压会改变水束高度、射程和池中的落点。广场和建造目录里的「海豚涌泉」使用同一实例场景，旧喷泉沿用存档里的 `fountain` 标识及原占地。

[喷泉原图](fountain.jpg) · [播放 6 秒原速视频](fountain-motion.mp4) · [水花局部动图](fountain-motion.gif) · [玩家墙面上的紫藤](wisteria.jpg)

海岛城四处、眠风山谷五处橘树采用同款承果枝和叶簇，每棵五个果实。果梗和果枝共用坐标，留出采摘时能看清的间隙。采摘会带走果实，树叶与树荫保留。枝叶避挡与果实同步，枝叶投影单独绘制。冰原岛的资源目录没有橘树。

| 物件 | 游戏中的用法 | 接手入口 |
| --- | --- | --- |

模型以米为单位，在工程根目录用 Godot 4.6.3 离线生成。执行 `godot --headless --path . --script res://tools/build_coastal_models.gd` 更新独立模型。海岛城和山谷加载已生成的网格。树影使用随枝梢分布的封闭叶簇，远处使用更少的三角形。路灯按街区合并绘制，遮光灯罩的光源朝向地面。贴图来源与校验值见[素材记录](../../../assets/terrain/coastal/source.json)。

## 实机验证

在工程目录运行 `python3 tools/dev.py test --suite coastal_town --windowed --timeout 200`。测试角色与玩家存档隔离。运行 `python3 tools/dev.py test coastal_modules_flow --windowed --game-arg=--capture-fountain` 可记录喷泉的连续画面。`python3 tools/dev.py test coastal_town_walk --windowed --game-arg=--night-soak --timeout 180` 可单独测量夜间广场连续转镜头一分钟。使用 `--game-arg=--build-soak` 可测量同样时长的建造场景。

### 验收结果

海岛城专项八个用例在同一批次全部通过（`20261120-175732-559529`），另复验山谷与冰原往返、房间照明、挂墙操作、采摘和存档规则。果梗验收逐一量取海岛城和山谷共 45 个挂点，连接误差小于 1 毫米。固定太阳与镜头，开关树冠投影后对比同一块地表，441 个采样点中有 370 个产生可见的明暗差。Metal 和 OpenGL 的喷泉运动、果树及建造功能检查各通过 67 项。

OpenGL 兼容渲染在连续进入海岛城、山谷并退出进程时报告 4 张纹理待回收，每张 21,844 字节。对改动前的 `a940587` 做相同两地图测试得到相同提示。

### 同机位性能

M1 Pro，Godot 4.6.3，Metal Forward+，均衡画质，4× MSAA，60 FPS 上限。输出 3024 × 1890，3D 缩放约 0.592，内部约 200 万像素。改动前的游戏提交为 `a940587`。两次测试使用相同角色、镜头路径、时间、分辨率与画质。每个机位预热 110 帧后走动或转镜头 4 秒，计时覆盖场景逻辑、画面绘制和提交。截图隐藏玩法界面，计时恢复界面，施工时显示编辑面板。

五个机位合计 1,208 帧，最长 36.98 毫秒，超过 50 毫秒的有 0 帧。在有焦点的全屏游戏窗口使用正常渲染循环，各转镜头约两秒。白天公园、夜间公园、白天海岸分别为 60.0、60.0、59.7 FPS。

夜间广场另连续转镜头一分钟，共 3,596 帧，平均 59.92 FPS，95% 帧耗时在 17.91 毫秒内，99% 在 30.08 毫秒内，最长 42.04 毫秒，超过 50 毫秒的有 0 帧。

建造编辑器另连续转镜头一分钟，共 3,602 帧，平均 60.03 FPS，95% 帧耗时在 19.07 毫秒内，99% 在 21.00 毫秒内，最长 24.81 毫秒，超过 50 毫秒的有 0 帧。

此前一次短时建造测试记录到 1 帧 87.02 毫秒的停顿。一次切换显示模式时，1920 × 1200 窗口曾出现约一秒的画面提交间隔。改成在显示切换结束、游戏窗口获得焦点后采样，同尺寸的白天公园、夜间公园和海岸分别为 59.8、60.0、59.5 FPS。两次窗口记录均可追溯。
