# 0.3.0 服务器与发布

服务位于47.119.37.251，Ubuntu24.04、2逻辑CPU、约3.5GiB内存，Godot4.6.3 Linux headless。游戏进程使用独立tutuworld系统用户，不与原应用共用数据。公网只使用已有TCP443，无需增加安全组端口；18891/18892仅绑定127.0.0.1，禁止向公网另行开放。

| 内容 | 位置/入口 |

## 日常维护

用`systemctl status tutuworld-world tutuworld-auth`检查服务。世界每10秒及关键结算时保存；退出角色也保存。进程异常由systemd重启。账号服务健康检查还会核对游戏监听端口，正式验收应同时做WSS握手，不仅检查HTTP200。

`tutuworld-backup.timer`每小时触发私有备份，保留14天；账号库使用SQLite备份API，世界JSON复制独立备份。备份在服务器本机，尚未配置异地容灾。恢复前停止两个游戏服务，保留故障数据副本，再恢复同一备份时间点的世界和账号，保持文件归tutuworld所有；不得重建世界起点或把试服数据混入。

一旦正式部署后，`world.json`中的epoch及clock_alignment必须保留。`tools/deploy_multiplayer.py align-clock --ssh-key <密钥路径>`只写入本机管理请求；世界执行一次校准并保存标记，重复请求不再调整。不要修改服务器系统时钟或给客户端开放调时接口。

## 构建与发布

```sh
python3 tools/build_release.py --godot /path/to/Godot --output /path/to/artifacts --part all
python3 tools/deploy_multiplayer.py prepare --ssh-key <路径> --artifacts <目录> --engine-zip <官方Linux引擎zip>
# 先在试服验证，正式启用会创建独立systemd服务和Nginx路由
python3 tools/deploy_multiplayer.py activate --ssh-key <路径>
python3 tools/publish_release.py --artifacts <目录> --signing-key <路径> --ssh-key <路径>
python3 tools/deploy_multiplayer.py status --ssh-key <路径>
```

当前部署工具面向0.3.0首发，有版本目录保护；后续升级必须先改版本及目录、保留数据，不能删released标记强行覆盖。每个发布目录不可修改，资源哈希验证完成后才切换签名清单。只公开客户端PCK、Mac/Windows压缩包和签名清单，不能上传服务端PCK、账号库、私钥或玩家数据。

Mac包为Apple Silicon/Intel通用、临时签名；未具备Developer ID公证。Windows为x86_64；已检查NVIDIA和AMD独显偏好导出值均为1，尚无Windows实体机及双显卡运行验收。版本、默认设置、PCK排除服务端以及Mac安装版实际更新重启另有验收记录。
