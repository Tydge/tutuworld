| `scripts/build_scene.gd` | 旧总生成入口会覆盖已确认的兔兔与 demo。实际仍使用的五个辅助函数原样抽到 `scripts/builders/scene_builder_base.gd`；城市、猫咪生成器改为继承新基类。 |
| `scripts/world.gd`、`scripts/garden_hud.gd` | 早期 demo 控制器/UI，不在正式 boot→title→双地图启动链；替代为共用 CityWorld 和当前 HUD。 |

| `tests/playthrough.gd`、`tests/refinement.gd` | 仅针对已退出的旧 demo，现有城市/山谷/角色回归承担验证。 |
| `tests/city_parse.gd` | 只打印部分脚本的旧检查，被会实际判错的 `project_integrity.gd` 全面替代。 |
| `tests/valley_geometry_probe.gd`、`tests/valley_navigation_probe.gd` | 旧一次性打印探针，通行/镜头/资源连通已有正式断言回归，重要排错结论写入指南。 |

**刻意保留的代码：**

- `scripts/bunny.gd` 是已确认兔兔场景的继承入口，有实际引用。
- `remote_transport.gd`、Session 的协议和时间边界是明确预留的联网接口，不把未启用误判成废代码。
- 角色生成器、其他有用途的模型/渲染诊断与行为回归仍可用；测试分组说明了哪些适合日常运行，不使用“所有旧测试都已过时”的删法。
- `scripts/city/forest_builder.gd` 与当前地图生成链、所有已确认模型/地图及素材原样保留。

```sh
mkdir -p /path/to/recovery
tar -xzf /path/to/2026-11-01-接手整理前备份.tar.gz -C /path/to/recovery
```

实际交付给开发者的日常入口是项目根目录及本文档组，不依赖旧 work 目录或归档才能运行。玩家的 `user://` 主进度、外部私钥和监控 SQLite 是有用数据，不属于过时开发产物。
