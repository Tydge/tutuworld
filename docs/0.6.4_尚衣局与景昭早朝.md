# 0.6.4 · 尚衣局与景昭早朝

玉京含章殿的兔子景昭会在游戏时间 07:00–11:00 登座。若御座已有玩家，他先开口请人让座。相同玩家继续坐满 10 秒，景昭会再次提醒并生气两秒。再过 15 秒，他会宣布散朝，去南市吃桂花糕。玩家可以一直坐着。在第三次发言前让座，他仍会走上御座。当天散朝后，宫中官员各归原处，早市照常开张。换地图、换本地角色或重启世界均保留退朝日期。次日早朝恢复。[含章殿实拍](evidence/含章殿早朝.jpg)

尚衣局一楼由掌衣绣筠售卖五件衣饰。绒花钿珠旗头 156 贝壳币、云水太极道袍 148 贝壳币、如意双铃长命锁 116 贝壳币、金章垂旒冕 188 贝壳币、衮金盘龙袍 8,888 贝壳币。二楼试衣镜可染底色、花纹色和纹样，三种角色都能试穿。[试穿实拍](evidence/尚衣局试穿.jpg)

四张地图的 328 句可选居民对白中，66 句按原文配了游戏里已有的动作，含商人问候、坊印回访和朱批回访。小葵再次自我介绍时挥手，阿圆找不到北时托腮思考，小笏踩到袖口时冒汗。多人由服务器选词，同图玩家看到同一个居民动作。两位客人可以同时听掌柜招呼、各自购物。

食物沿用物品自己的模型。手持点心、喝茶和分段进餐时，角色与同图旁观者都能看见对应食物和动作。修正了御座的金色交互提示球挡在景昭面前的显示问题。

[下载最新完整客户端](https://47.119.37.251/tutuworld/download)。Windows 或 Mac 浏览器会自动下载对应的安装包，其他设备会显示系统选择。固定地址按当前正式清单取版本。旧版地址继续提供原文件，已安装的启动器可照常检查更新。

## 复验

- 商店试穿、三物种染色、占座提示、存档和隔天复朝见 `palace_clothing_shop`。两个实际联机客户端的抢座、断线、同图表情、当天重载、早市路线和同时购物见 `palace_multiplayer_flow`。
- `dialogue_gesture_coverage` 核对 328 句对白和 66 个匹配。`npc_dialogue_rules` 核对角色与时段。`regional_meals`、`meal_presentation_flow` 和 `multiplayer_rules` 覆盖进食与多人呈现。
- 0.6.4 使用 build 16、协议 5 和启动器 2。发布切换与恢复位置见[服务器运维](服务器运维.md)。

## 正式发布

2026 年 11 月 29 日，Linux 隔离试服通过五客户端入场、重登和广播验证。正式服切换前记录到 0 个游戏连接。首次切换后，核对程序误读了备份目录，正式服务额外重启了一次。使用切换前的成对备份重新核对，3 个账号、4 个角色、照料记录、地皮与三张地图的 154、102、12 条建筑记录全部一致，随后才推广新清单。

从固定入口分别完整下载了 Mac 和 Windows 安装包，SHA-256 均与本地成品一致。旧版 0.3.0 至 0.6.3 的 26 个安装包地址全部返回 200。公网多人握手接受 build 16 并提示旧客户端更新。游戏自己的更新器下载并验签了 251,772,684 字节的资源包。Mac 通用程序已验签，在 Apple Silicon 上启动新版，并用上一版启动器加载本版签名资源。Windows x64 安装包已解压核对程序、资源包和 D3D12 运行库，尚未在 Windows 实机运行。部分强制退出的无画面原生启动测试报告渲染资源仍被引用。[构建文件大小与摘要](evidence/production-0.6.4/artifacts.json)
