# 0.5.1 冰原、服饰与农田更新

2026-11-22 发布 **0.5.1 / build 11**。启动器为 2，联网协议为 5。发布标签为 `v0.5.1`。已有客户端可在游戏内检查更新，下载后重启。

## 本版内容

- 冰原开放八块 24 × 20 米地皮与三款冬屋样板。旅舍可以住宿，面包房可烤路粮，茶室可煮松针茶，踏雪图册记录三个印章。城镇和雪镇的试衣架可为已拥有的衣物换色换纹。
- 兔子、三花猫和熊猫均可穿戴牛仔帽、礼帽、连身裙、衬衫、红缎领结和大金链子。默认 22 位居民中有 4 位穿上新品。数字键 1–0 可做十种角色动作，同图玩家可看到动作、表情和特效。
- 胡萝卜、生菜、番茄、南瓜和小麦各有五个生长阶段，田间杂草有两种生长形态。浇水先对准田块、双手持壶，再从六个真实喷孔向下倾倒。作物采用共享模型批量渲染。
- 自建餐桌的配套餐椅按建筑所属地图查找。联机玩家可以在已建好的房屋里入座、用餐、取消和起身。

## 上线验收

客户端构建源为 `e575269`，服务端在 `0476c87` 修复餐椅后单独重新导出。两个安装包和签名内容包都从固定 HTTPS 地址下载并通过 SHA-256 比对。Mac 通用二进制检查了两个架构和签名。Windows 检查了 0.5.1.0 版本资源、D3D12 运行库和许可证。此次覆盖 Mac 原生启动，Windows 实机与 Mac 公证未覆盖。Godot 的无界面原生进程退出时仍有资源清理提示。[产物大小与摘要](evidence/production-0.5.1/artifacts.json)

22 项发布回归和 6 项附加检查通过。发布回归发现跨地图调整影响了自建餐椅的查找，修复后重跑多人入座和起身检查。两项建造测试的场景桩也补齐了地图标识。在最终 Linux 服务端包上，59 项多人建造与 114 项冰原检查通过，涵盖买地、发布、试染、保存和新服饰。隔离联机核对了双客户端的动作同步、新居民穿搭和旧构建更新提示。[本地回归](evidence/production-0.5.1/local-validation.json) · [Linux 与公网验证](evidence/production-0.5.1/verification.log)

切换前暂停正式服务，成对备份世界 JSON 和 SQLite 账号库。首次比对触发短暂回退，原因是五条照料时间戳在 JSON 浮点往返中相差一个最低有效位，最大约为 0.23 纳秒。复核后重新取快照，复验只对照料时间戳允许一个最低有效位的差异，其他照料字段和顺序均逐项比较。最终私有快照位于服务器 `/root/tutuworld-deploy-backups/0.5.1-20261122-final`。[正式数据比对](evidence/production-0.5.1/preservation.json)

正式服保留了全部账号、角色、建筑、地皮、资源、作物、照料记录、居民搭配和原世界时钟。推广签名清单后，通过公网 HTTPS 和 WSS 检查新版本准入与旧构建拦截；使用 0.5.0 的 Mac 原生程序挂载公网下载的更新并加载新作物和服饰。[公网验收](evidence/production-0.5.1/verification.log)
