# 兔兔的世界

Godot 4.6.3 的 3D 生活模拟游戏。正式版 **0.5.0 / build 10** 开放海岛城、眠风山谷和冰原岛。海岛城南码头可乘船前往山谷或冰原，各收 10 贝壳币，回城免费。已有玩家可在游戏内检查更新、下载并重启。

[Windows x64 下载](https://47.119.37.251/tutuworld/releases/0.5.0/TutuWorld-Windows.zip) · [Mac 通用版下载](https://47.119.37.251/tutuworld/releases/0.5.0/TutuWorld-macOS.zip) · [0.5.0 发布记录](docs/0.5.0_发布与部署记录_2026-11-20.md)

- 冰原岛新增霜光雪镇和蓝冰原、16 栋可进入的建筑、32 处采集点、冬装和居民试穿。玩家基础步行增加到 3.5，跑步增加到 5.95，跑步免耗耐力。冰面会保留滑行惯性。[冰原岛与移动调整](docs/冰原岛与移动调整_2026-11-18.md)
- 海岛城重做出生广场、海豚涌泉、商街与远景。海岛城及山谷的橘子随枝生长。海豚涌泉、紫藤壁挂花箱和冬季家具也可用于玩家建造。[海岛城实机验收](docs/evidence/coastal-town-20261120/README.md) · [建造模式](docs/建造模式.md)
- 猫咪的头脸与耳根采用连续曲面。脸部毛色和五官随场景光线变化，海岛城阳光下的角色阴影条纹已修正。

开发分支的冰原岛可在雪镇买两块地皮，在蓝冰原的南岸与北山脚各买三块，均为 24 × 20 米。立板旁按 E 认购，靠近自己的地皮按 F6 建造。松枝茶屋、炉火山舍和雪岭驿馆在建造栏的样板房中。云朵服装店和绒雪裁缝店的试衣架可试染已有衣物。北坡书屋的《踏雪图册》记录沿途的三枚印章，面包房可烤随身路粮，围炉茶室能煮松针茶，两间旅舍的床都可以睡。

本地独立试玩可双击[冰原预览](tools/本地冰原预览.command)或[山谷预览](tools/本地山谷预览.command)。普通 Godot F5 单人游戏使用真实存档。接手见[开发指南](docs/开发接手指南.md)，多人和更新见[接口文档](docs/接口文档.md)。

用Godot打开`project.godot`，完成首次导入后F5；无需额外建模插件。Python 3.9+仅用于开发工具，在项目根目录运行：

```sh
python3 tools/dev.py doctor
python3 tools/dev.py test --suite icefield --windowed --timeout 240
python3 tools/dev.py run
```

引擎可通过`GODOT_BIN`环境变量或`python3 tools/dev.py --godot /path/to/Godot doctor`指定。测试产物写`.qa-artifacts/`，玩家存档、密钥和构建产物不提交Git。

## 操作

- WASD／方向键移动，Shift切换走跑，空格跳跃；右键拖动视角，滚轮缩放。
- E互动，F快捷照料选中的作物；多人回车打开聊天，再回车发送文字/emoji气泡，Esc取消。
- C角色，I／B背包，Tab换装，M地图，Esc返回/取消/设置；R发呆，F2取景，F12拍照，靠近本人已购地皮后F6建造（单人/多人）。
- 开发版数字键动作：`1` 大笑、`2` 生气、`3` 伤心、`4` 托腮思考、`5` 平躺、`6` 坐下、`7` 指向前方、`8`～`0` 三支循环舞蹈。移动或跳跃取消动作。
