# 兔兔的世界

**0.6.3 / build 15 · 第四章玉京城**　从海岛城南码头乘船可去眠风山谷、冰原岛或玉京城。三条航线均为出城 10 贝壳币，回城免费。已有玩家检查更新、下载并重启，即可继续在正式服多人游玩。

- 玉京城开放南市、玉带河与宫城。坊间有 41 处小游戏，云锦庄有十二款中式衣饰。百工坊还可织造六款。开发版的宫城尚衣局另售旗头、道袍、长命锁，以及兔皇帝景昭穿戴的垂旒冕和盘龙袍。西郊有 288 块公共田，六里宅地能手建、放样板及拖墙扩建含章殿等房型，多位主人可同时在各自地皮施工。[玉京城玩法](docs/玉京城.md)
- F1–F9 可用九个新表情，F10–F12 可跳芭蕾、街舞和云手团扇舞。多人按 Enter 向全服聊天。
- 九首配乐按地图、昼夜和建造模式切换。标题页和游戏中的「设置」都可独立调整背景音乐，默认开启、音量 50%。

- 冰原岛新增霜光雪镇和蓝冰原、16 栋可进入的建筑、32 处采集点、冬装和居民试穿。玩家基础步行增加到 3.5，跑步增加到 5.95，跑步免耗耐力。冰面会保留滑行惯性。[冰原岛与移动调整](docs/冰原岛与移动调整_2026-11-18.md)
- 海岛城重做出生广场、海豚涌泉、商街与远景。海岛城及山谷的橘子随枝生长。海豚涌泉、紫藤壁挂花箱和冬季家具也可用于玩家建造。[海岛城实机验收](docs/evidence/coastal-town-20261120/README.md) · [建造模式](docs/建造模式.md)
- 猫咪的头脸与耳根采用连续曲面。脸部毛色和五官随场景光线变化，海岛城阳光下的角色阴影条纹已修正。

冰原岛可在雪镇买两块地皮，在蓝冰原的南岸与北山脚各买三块，均为 24 × 20 米。立板旁按 E 认购，靠近自己的地皮可点击底栏「建造」。松枝茶屋、炉火山舍和雪岭驿馆在建造栏的样板房中。云朵服装店和绒雪裁缝店的试衣架可试染已有衣物。北坡书屋的《踏雪图册》记录沿途的三枚印章，面包房可烤随身路粮，围炉茶室能煮松针茶，两间旅舍的床都可以睡。

胡萝卜、生菜、番茄、南瓜和小麦各有五个生长阶段。角色会双手倾壶浇地。牛仔帽、礼帽、连身裙、衬衫、红缎领结和大金链子可在服装店试穿，已买的衣物可以在试衣架换色换纹。数字键 1–0 可做十种角色动作。

本地独立试玩可双击[冰原预览](tools/本地冰原预览.command)或[山谷预览](tools/本地山谷预览.command)。普通 Godot F5 单人游戏使用真实存档。接手见[开发指南](docs/开发接手指南.md)，多人和更新见[接口文档](docs/接口文档.md)。

## 源码试玩操作

- WASD／方向键移动，Shift切换走跑，空格跳跃；右键拖动视角，滚轮缩放。
- E互动，F快捷照料选中的作物；多人按回车打开左下角世界聊天，再按回车发送，Esc 取消。所有地图共享最近 5 条发言，每条显示最多 15 秒，近处角色同时显示头顶气泡。
- C角色，I／B背包，Tab换装，M地图，Esc返回/取消/设置；R发呆，Shift+F2 取景，Shift+F12 拍照，靠近自己的地皮按 Shift+F6 建造（单人/多人）。
- 数字键动作：`1` 大笑、`2` 生气、`3` 伤心、`4` 托腮思考、`5` 平躺、`6` 坐下、`7` 指向前方、`8`～`0` 三支原有循环舞蹈。
- 短表情持续 2 秒。`F1` 打招呼、`F2` 欢呼、`F3` 感谢、`F4` 爱你、`F5` 同意、`F6` 不要、`F7` 偷偷坏笑、`F8` 流一大滴汗、`F9` 震惊。再按可重播，移动或跳跃可打断。[三种动物的九个表情实拍](docs/evidence/social-emotes-20261126/nine-emotes.mp4)
- 三支循环舞蹈分别为`F10` 芭蕾（12 秒），`F11` 或 `G` 街舞（13⅓ 秒），`F12` 云手团扇舞（14.4 秒）。再按同一舞蹈键、移动或跳跃即可停止。[三种动物的完整舞蹈实拍](docs/evidence/stage-dances-20261126/three-dances.mp4)
