# 玉京美术来源

建筑、园林、树、服装、工具和场景均在 Godot 中建模和烘焙。四张玩家参考图用于观察街道比例、建筑层次和灯色。下列原创纹理通过 ImageGen 生成，图集按象限裁成运行时材质。远山保留透明天际线，枝叶图集使用透明裁切。

各栋的院坪、檐脚背光和衔接的巷道随地图离线绘进一张 1024 方图。筒瓦、瓦当和滴水使用烘焙网格，近看有弧面和阴影。街屋墙面和檐柱的顶端背光与石阶反光烘进顶点颜色，远景网格保留同一组颜色。街边树和玩家栽种的玉京树共用相机避挡，遮挡范围取实时相机到角色的线段，树影保持完整。柳、梅、银杏和香樟各有树皮颜色，基部有露根，侧枝从不同高度弯出。庭院松和街树按地形落点定位。近景石板以石缝和磨亮的表面还原浅浮雕光照，沿用已采样的纹理。
