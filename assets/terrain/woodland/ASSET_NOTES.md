# Woodland v1 — local valley redesign, 2026-11-17

`foliage_atlas_v1.png` and `forest_turf_v1.png` were generated with the built-in image_gen tool and copied unchanged into this project. The transparent foliage atlas has cedar / fir on the left and oak / birch on the right. Atlas quadrants are selected by UVs; there is no Python pixel editing. The game samples both assets with mipmaps, anisotropic filtering and VRAM compression; leaf cards use alpha scissor instead of blended transparency.

The exact generation prompts are in [prompts.json](prompts.json). Original generated outputs, dimensions and shipped-file SHA256 hashes are recorded in [source.json](source.json). The generated-output paths are provenance only, never runtime dependencies. Bark, path earth and mossy rock reuse the existing project assets and their original provenance.

`../water_ripple_normals_v1.png` is a deterministic, periodic 512×512 normal map generated by `tools/build_water_normals.gd` from 18 analytic waves, seed 743260. It is not AI-generated. It uses lossless normal-map import and mipmaps. The two scrolling water samples share this one texture. No extra world capture or planar-reflection camera is introduced for water.

This work shipped in 0.4.1 on 2026-11-17. It is not part of the previously published 0.4.0 package; the provenance and generation prompts above remain unchanged.
